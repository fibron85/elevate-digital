# Elevate Digital — Luxury Black & Gold Website

A responsive digital marketing agency website for UAE and worldwide clients. Built with plain HTML, CSS and JavaScript; no build process is required.

## Included
- Luxury black-and-gold visual design
- Responsive mobile/tablet/desktop layout
- Social Media Marketing, SEO, Website Design, Facebook Ads and Instagram Ads service sections
- Creative concept previews (illustrative, not client case studies)
- Process section and custom-quote packages
- WhatsApp and email enquiry links plus an enquiry form
- Basic SEO metadata and accessible form labels

## Before publishing: configure contact details
Open `script.js` and replace:
- `BUSINESS_EMAIL = "hello@yourbusiness.com"` with your real business email.
- `WHATSAPP_NUMBER = "971500000000"` with your real WhatsApp number, digits only, including country code. Do not include `+`, spaces or hyphens. For a UAE number, use country code `971` and omit the leading local `0`.

The WhatsApp and email actions intentionally show a setup message while the placeholders remain. The contact form uses `mailto:` and opens the visitor's email application; it does not save enquiries in a database or send email directly from a server. If you want enquiries stored online, connect a form service or backend later.

## Preview locally
Open `index.html` in a modern browser. Internet access is used to load Google Fonts; the website layout itself is static and does not require a build tool.

## Free deployment with GitHub Pages
1. Extract `elevate_digital_luxury_website.zip` on your computer.
2. Sign in to GitHub and create a new repository, e.g. `elevate-digital`.
3. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish and copy the URL displayed on the Pages settings screen.
8. Open the live site on your phone and desktop; test the navigation, email and WhatsApp links.

## Custom domain (optional)
You do not need a domain to publish. You can use the free GitHub Pages URL initially. When you buy a domain, go to **Settings → Pages → Custom domain** and follow the DNS records GitHub provides. DNS records depend on the registrar, so use the exact values shown by GitHub.

## Before marketing the site
- Replace both contact placeholders and test on mobile.
- Replace illustrative portfolio visuals with real client work before describing them as projects.
- Add a privacy policy if you add analytics or collect personal information through an online form service.
- Verify your service scope, legal/business details and any claims before launch.
- Advertising spend and third-party platform fees are not included in the custom-quote package descriptions.
